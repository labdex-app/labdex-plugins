# Security policy

## Supported versions

Only the live site, built from `main`, is supported.

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report them privately through GitHub: open the repository's
[Security tab](https://github.com/labdex-app/labdex-plugins/security) and click **Report a vulnerability**.
Include:

- the page or URL that is affected;
- steps to reproduce, or a proof of concept;
- what an attacker could do with it.

We aim to answer within a week and to ship a fix as soon as we can. We credit you in the release
notes unless you'd rather stay anonymous.
